# コピー＆ペースト機能 SPEC.md

## 説明

### 機能説明と背景

#### 課題

PCEにおける量子誤り検出デモで使用した量子回路の作成を通じ、本機能導入の必要性が明確になった。

量子アルゴリズムの量子回路を QniGPU 上で構築する際、量子ゲートを都度ドラッグ＆ドロップで配置する操作は、ゲート数の増加に伴い手間と時間が累積する。

特に CNOT ゲートとの組み合わせ、たとえば CNOT + S、CNOT + 位相、CNOT + H などは多くの量子アルゴリズムで登場する。
これらを繰り返し配置する場合、この問題が顕著になる。

改善目標は、操作回数と所要時間を削減し、回路構築の効率と正確性を高めることである。

#### 解決案

QniGPU にコピー＆ペースト機能を導入する。

本機能では、ペーストを「コピーした量子ゲート群を右方向にステップ挿入する操作」として定義する。

これにより、量子回路の編集における操作回数と編集時間を低減し、ユーザー生産性を向上させる。

#### 効果の試算

タイムアタックの試算は以下を前提とする。

- 単一ゲートドラッグ: 1.0 秒
- コピー / ペースト: 0.2 秒
- 回路内調整: 0.5 秒

従来の手順では、パレットからドラッグ 52 回で約 52 秒かかる作業が、本機能を用いることで合計約 15.8 秒となる。

作業時間で概ね 70% 程度の削減が見込まれる。
ドラッグ回数は 52 回から 4 回になり、約 92% 減となる。

#### 注意点

制御ゲート構造のまとめて選択は初期実装対象とする。

ドラッグ矩形選択はコピー対象を効率よく指定するための選択手段として扱う。

下方向ペーストについては必要性が判明してから実装する。

### 用語定義

| 用語 | 意味 |
|---|---|
| ゲート(量子ゲート) | H(アダマール)、X、S、T、制御ゲート、ターゲットゲート、SWAPなど、量子回路上に配置される操作単位 |
| ステップ | 量子回路の縦の列。時間方向・右方向に増える単位 |
| 量子ビット | 水平方向の線として描画される行 |
| セル | 1つの量子ビット行と1つのステップ列が交差する位置。ゲートがフィッティングされ配置される場所 |
| 空セル | ゲート実体が存在しないセル。制御線だけが通っているセルも、ゲート実体がなければ空セルとして扱う |
| ゲート実体 | 選択・コピー・ペースト対象になる実際のゲート要素。制御線だけはゲート実体として扱わない |
| 制御線 | 制御ゲートとターゲットゲートを接続する線 |
| 制御ゲート構造 | 制御ゲート、ターゲットゲート、制御線、接続情報を含む、CNOT・制御Z・制御H・CCNOTなどのまとまり |
| SWAP構造 | SWAPを構成する複数のSWAP部品と接続線のまとまり |
| selectedGates | 現在選択されているゲート集合。Ctrl+C のコピー対象 |
| pasteAnchorCell | 挿入アンカーとなるセル。Ctrl+V はこのセルの右隣を起点に実行する |
| clipboard | Ctrl+C により保存されたゲート集合、相対座標、接続情報 |
| pastedGates | 直近の Ctrl+V により新規配置されたゲート集合 |
| pastedSteps | 直近の Ctrl+V により新規配置されたゲートを含むステップ集合。白いフェード強調表示の対象 |
| コピー範囲 | Ctrl+C 時に `selectedGates` から作られるコピー対象。選択ゲートが存在するステップだけを左詰めし、量子ビット方向の間隔は保持する |
| 相対座標 | コピー範囲内での各ゲートの相対的なステップ差分・量子ビット差分。ステップ方向は未選択ステップを除いて再採番する |
| insertStartStep | ペースト挿入開始ステップ。通常は `pasteAnchorCell.step + 1` |
| insertWidth | クリップボード内のステップ幅。既存ゲートを右へ押し出す幅でもある |
| 押し出し対象 | `insertStartStep` 以降に存在し、ペースト時に右方向へ移動される既存ゲート |
| Undo単位 | 回路を変更する1操作。ペースト、ゲート配置・移動・削除・切り取り、Clearをそれぞれ1単位として扱う |

### 状態定義

#### selectedGates

`selectedGates` は、コピー対象として選択されているゲート集合である。

- ゲートをクリックすると、そのゲートが `selectedGates` に入る。
- 通常クリックで別のゲートを選択した場合、既存の `selectedGates` は解除され、クリックしたゲートに置き換わる。
- Shift + クリックにより、複数ゲートを `selectedGates` に追加できる。
- Ctrl+C は `selectedGates` をコピー対象とする。
- `selectedGates` と `clipboard` は独立した状態である。
- 新たなゲート選択や空セル選択が行われても、既存の `clipboard` は変更しない。

#### pasteAnchorCell

`pasteAnchorCell` は、挿入アンカーとなるセルである。
画面上ではセル選択枠ではなく、ペースト位置マーカーとして表示する。

- ゲートをクリックした場合、そのゲートが存在するセルを `pasteAnchorCell` とする。
- 通常クリックでゲートを選択した場合、`pasteAnchorCell` はそのゲートのセルに更新する。
- 空セルをクリックした場合、その空セルを `pasteAnchorCell` とする。
- 空セルクリックでは、既存の `selectedGates` は解除しない。
- Ctrl+C 実行時、`pasteAnchorCell` はコピー範囲の右上セルに更新する。
- Ctrl+V は `pasteAnchorCell` を基準に実行する。
- Ctrl+V 実行後、`pasteAnchorCell` は自動更新しない。
- 連続して Ctrl+V が実行された場合も、同じ `pasteAnchorCell` を基準にペーストする。
- 量子回路外やセル以外の背景クリックでは、`selectedGates` と `pasteAnchorCell` を解除する。
- Escapeでも `selectedGates` と `pasteAnchorCell` を解除する。
- 空セルが `pasteAnchorCell` でなくなった場合、その空セルだけで構成される空ステップは既存の回路整理機能で詰めてよい。
- 新たに選択された空セルのステップは、挿入アンカーとして残すため詰めてはならない。

#### clipboard

`clipboard` は、Ctrl+C により保存されたゲート集合である。

保存する情報は以下とする。

- ゲート種類
- ステップ相対位置
- 量子ビット相対位置
- 制御ゲート・SWAPなどの接続情報
- 必要な描画・更新に必要な情報

`clipboard` の更新ルールは以下とする。

- `clipboard` は Ctrl+C 実行時のみ更新する。
- 新たなゲート選択、Shift + クリック、空セル選択、Ctrl+V、Ctrl+Z、Ctrl+Y、Ctrl+Shift+Z では `clipboard` を変更しない。
- `selectedGates` が空の場合、Ctrl+C は何もしない。
- `selectedGates` が空の Ctrl+C でも、既存の `clipboard` は保持する。

#### pastedGates

`pastedGates` は、直近の Ctrl+V で追加されたゲート集合である。

- `pastedGates` は、ペースト後の強調対象ステップを決めるために使用する。
- ペーストされたゲートは `selectedGates` に自動追加しない。
- 連続ペースト時、今回新しく作成されたゲートは新たにペースト強調表示を開始する。
- 前回の Ctrl+V で作成されたゲートが、今回の Ctrl+V により右方向へ押し出された場合でも、そのゲートのフェードアウトは停止しない。
- 押し出された前回ペーストゲートは、既に開始しているフェードアウトをそのまま継続する。

#### pastedSteps

`pastedSteps` は、直近の Ctrl+V で新規配置されたゲートを含むステップ集合である。

- ペースト強調表示は、`pastedSteps` に含まれるゲート実体と、制御ゲート・SWAPの縦接続線へ適用する。
- 量子ビットの横線は、ペースト強調表示の対象に含めない。
- ゲートと縦接続線で白さやフェード量に差が出ないよう、同じ不透明度と同じフェード時間を使用する。
- 押し出されただけの既存ステップは、今回の `pastedSteps` に含めない。

### 選択仕様

#### 通常選択

- 量子ゲートの選択枠 `border-active` は、コピー対象ゲートを示す。
- 機能実装前の状態では、量子ゲートの `border-active` 色の枠は activeGate の UI として存在している。
- コピーしたい対象の量子ゲートを `border-active` 色の枠に切り替えて判断する。
- 選択枠は、現在のコピー対象を示す恒常的な表示である。
- 選択枠はホバー表示とは独立したレイヤーで保持し、選択ゲートまたは別のゲートへのホバー開始・終了によって消してはならない。
- 挿入アンカーは、選択枠ではなくペースト位置マーカーで示す。
- 初期状態では、ゲートまたは空セルがまだ選択されていないため、選択枠は表示されない。
- 一度ゲートが選択された後、選択枠は解除操作まで表示され続ける。
- 選択枠は、ペースト後も解除しない。
- 選択枠は、新たなゲート選択または空セル選択により更新される。
- Clear、リロード、または回路を初期状態へ戻す操作が行われた場合、選択枠は初期状態に戻り、表示されない。
- Escapeまたはセル以外の背景クリックでも、選択枠とペースト位置マーカーを解除する。
- 複数の論理操作を選択した場合、選択セルが上下左右に接する形の外周を灰色点線で描画する。点線はゲート枠から2px空け、ゲート枠へ重ねない。
- 点線は4pxの線と2pxの空白を一周期とし、外周・内周・ゲート間の境界を通して同じ周期を保つ。角では隣り合う辺の半線分を合わせ、線が途切れたり二重の長さになったりしないようにする。
- 外周はL字、凸型、凹型、テトリス型などの選択形状に沿わせ、単純な外接矩形にはしない。
- 選択形状に完全に囲まれた未選択セルがある場合、そのセルの周囲にも内周の点線を描画する。
- 離れた選択は、無理につなげず個別の外周として表示する。
- CNOT、CCNOT、CCCNOT、CZ、CCZ、SWAPなど、回路データ上の縦線で接続されたひとつの構造だけを選択した場合は、ひとつの論理操作として扱い、複数選択用の点線を表示しない。
- 接続構造を2つ以上、または接続構造と別のゲートを同時に選択した場合は、複数の論理操作として点線を表示する。

#### 複数選択

- `Shift` キーを押し続けた状態で複数のゲートをクリックすると、複数選択できる。
- Shift + クリックにより、既存の `selectedGates` にゲートを追加できる。
- 通常クリックで別のゲートを選択した場合、既存の `selectedGates` は解除され、クリックしたゲートに置き換わる。
- 空セルクリックでは、既存の `selectedGates` は解除しない。

#### 制御ゲートの選択

制御ゲート構造は、制御ゲート、ターゲットゲート、制御線、接続情報から構成される。

制御ゲートまたはターゲットゲートをシングルクリックした場合、そのゲートが属する接続構造全体を選択する。

CNOTの場合、制御ゲートをシングルクリックしても、ターゲットゲートをシングルクリックしても、CNOT構造全体を選択する。

通常ゲートが同じステップに複数並んでいるだけの場合、それらは接続構造として扱わない。

たとえば、同じステップに H / S / T が並んでいても、Hをクリックしただけで S / T まで選択してはならない。

制御ゲート構造やSWAP構造のまとめて選択は、ゲート名、表示形状、SVG上の見た目から判定してはならない。

まとめて選択する対象は、既存の回路データが持つ接続情報を正として判定する。

制御線の描画オブジェクトはゲート実体ではないため、選択対象には含めない。

対象例:

- CNOT
- 制御Z
- 制御回転ゲート
- 制御H
- CCNOT
- SWAP

#### 制御ゲートの一部選択

制御ゲートまたはターゲットゲートをダブルクリックした場合、そのクリックされたゲート実体だけを単独選択する。

制御ゲートをダブルクリックした場合、その制御ゲートだけを単独選択する。

ターゲットゲートをダブルクリックした場合、そのターゲットゲートだけを単独選択する。

単独選択された制御ゲートまたはターゲットゲートを Ctrl+C した場合、接続構造全体を自動でコピーしてはならない。

この場合、選択された1個のゲート実体だけをコピーする。

制御ゲートを単独コピーした場合、ペースト後も単独の制御ゲートとして配置する。

制御線は、制御ゲート単独が保持するものではない。

制御線は、同じステップ内に接続対象となるゲートが存在する場合に描画・更新される。

制御ゲートの接続対象は、Qni内部で「制御可能」と定義されているゲートに限る。

測定ゲート、初期化ゲート、ブロッホ球など、Qni内部で制御可能と定義されていない要素は、同じステップ内に存在しても制御ゲートとは接続しない。

#### 空セルの選択

- 空セルは、挿入アンカーとして選択可能とする。
- 制御線が描画されていても、そのセルにゲート実体が存在しない場合、そのセルは空セルとして扱う。
- 空セルクリックは、挿入アンカーセルの変更であり、既存の `selectedGates` を解除する操作ではない。
- 空セルを選択しても、既存の選択ゲート枠は維持する。
- 空セルの挿入アンカーは、ゲート選択枠と同じ枠では表示しない。
- 空セルを挿入アンカーにした場合も、挿入位置を示すペースト位置マーカーを表示する。
- 空セル選択は、Dropzone またはセル領域に対するクリックで発生する。
- 回路グリッド内であっても、Dropzone / セル領域に入っていないクリックは、空セル選択として扱わない。
- ワイヤ上のクリックであっても、Dropzone / セル領域外であれば `pasteAnchorCell` は変更しない。
- クリック位置を最も近いセルへ自動補正してはならない。
- 量子回路外やセル以外の背景クリックでは、空セルの挿入アンカーを解除する。
- 空セルを選択した後、別のゲートまたは別ステップの空セルを選択した場合、前の空セルは `pasteAnchorCell` ではなくなる。
- 前の空セルだけで構成される空ステップは、その時点で既存の回路整理機能により詰める。
- 同じステップ内の別セルへ挿入アンカーを移した場合、そのステップは詰めない。

#### ステップバーの扱い

回路グリッド内には、各ステップの量子状態を表示するためのステップバーが存在する。

ステップバーは、ゲート配置セルではない。

ステップバーをクリックした場合、既存のステップ選択・量子状態表示切り替え処理を行う。

ステップバーのクリックは、空セル選択として扱わない。

ステップバーのクリックにより `pasteAnchorCell` を変更してはならない。

ステップバーのクリックにより `selectedGates` を解除してはならない。

ステップバーは、コピー＆ペースト機能における挿入アンカーセルではない。

### キーボード操作仕様

コピー＆ペースト機能で扱うキーボード操作は、量子回路エディタにフォーカスがある場合のみ処理する。

ブラウザ標準操作や入力フォームの編集を妨げてはならない。

#### 対象キー

| 操作 | 動作 |
|---|---|
| Ctrl+C | `selectedGates` を `clipboard` に保存する |
| Ctrl+X | `selectedGates` を `clipboard` に保存してから削除する |
| Ctrl+V | `pasteAnchorCell` を基準に `clipboard` を挿入する |
| Ctrl+Z | 直前の回路編集をUndoする |
| Ctrl+Y / Ctrl+Shift+Z | Undoした回路編集をRedoする |
| Ctrl+A | 回路上のすべてのゲートを選択する |
| Delete / Backspace | `selectedGates` のゲートを削除する |
| Escape | `selectedGates` と `pasteAnchorCell` を解除する |

#### キーイベントの扱い

- 入力欄、テキストエリア、コンテンツ編集可能要素にフォーカスがある場合は処理しない。
- 対象キーを処理した場合のみ、ブラウザ標準動作を抑止する。
- `clipboard` が空の Ctrl+V、`selectedGates` が空の Ctrl+C、削除対象がない Delete / Backspace は何もしない。
- 何もしない場合でも、既存の `clipboard`、`pasteAnchorCell`、`selectedGates` を不用意に消してはならない。

#### Delete / Backspace

Delete / Backspace は、選択中のゲートを削除する操作である。

- 削除対象は `selectedGates` に含まれるゲート実体のみとする。
- 制御ゲート構造がまとめて選択されている場合は、選択された構造を構成するゲート実体を削除する。
- 削除後は、制御線・SWAP接続線などの接続表示を必ず再計算する。
- 削除後に空ステップができた場合は、既存の回路整理機能に従って詰めてよい。
- Delete / Backspace は、コピー済みの `clipboard` を変更しない。
- Delete / Backspace は、1回の削除を1単位としてUndo/Redo履歴へ保存する。

### コピー仕様

#### Ctrl+C

- `Ctrl+C` は、現在の `selectedGates` を `clipboard` に保存する。
- 選択したすべてのゲートは `Ctrl+C` でクリップボードに保存される。
- `selectedGates` が空の場合、Ctrl+C は何もしない。
- このとき、既存の `clipboard` は変更しない。
- Ctrl+C を実行した場合、`pasteAnchorCell` はコピー範囲の右上セルに更新する。
- コピー範囲の右上セルとは、`selectedGates` の中で最も右にあるステップ、かつ最も上にある量子ビットのセルである。
- Ctrl+C 後に別のゲートまたは空セルを選択した場合、`pasteAnchorCell` はその選択先に更新される。
- ただし、`clipboard` は新たな Ctrl+C が実行されるまで変更しない。

#### 複数ゲートのコピー

- 複数の量子ゲートをコピーした場合、種類だけでなく構造(各量子ゲートのステップ・量子ビットの位置)を保存する。

保存対象は以下とする。

- どの量子ビットにあるか
- どのステップにあるか
- 選択ゲート群の相対座標
- 制御ゲートの接続関係
- SWAPなどの複数量子ビット構造

#### コピー保持

- 選択してコピー後、ブラウザを閉じたり、他ブラウザで操作があった場合を除き、コピーした量子ゲートを保持する。
- 複数選択しコピー後、新たなゲート選択または空セル選択が行われても、既存の `clipboard` は保持される。
- `clipboard` が更新されるのは、新たに Ctrl+C が実行された場合のみである。

### ペースト仕様

#### 基本定義

`Ctrl+V` によるペーストは、コピーされた量子ゲート群を右方向にステップ挿入する操作である。

ペーストは上書きではない。

ペースト予定位置に既存ゲートが存在する場合、既存ゲートを右方向へステップごと押し出す。

#### 挿入アンカー

ペーストは `pasteAnchorCell` を基準に実行する。
ペースト位置は、`pasteAnchorCell` の右隣に表示されるペースト位置マーカーで示す。

基本ルール:

- `pasteAnchorCell` はコピーしたゲート群の最も右のステップ・最も上の量子ビットにする。
- コピーしたゲート群の挿入開始位置は、基準セル(`pasteAnchorCell`)の1ステップ右とする。
  - `insertStartStep = pasteAnchorCell.step + 1`
- コピーしたゲートが存在するステップ数を `insertWidth` とする。
  - `insertWidth = clipboard.selectedStepCount`
- ペースト時は `insertStartStep` 以降の既存ゲートを `insertWidth` 分だけ右方向へ押し出す。
- clipboard 内の最小 step・最小 qubit の位置を、`insertStartStep` と `pasteAnchorCell.qubit` に合わせて配置する。
- その他のゲートは、clipboard 内の相対座標を維持して配置する。
- Ctrl+V 実行後、`pasteAnchorCell` は自動更新しない。
- 連続して Ctrl+V が実行された場合も、同じ `pasteAnchorCell` を基準にペーストする。
- Ctrl+V の連打は、末尾へ追記する操作ではなく、同じ基準セルの右側へ繰り返しステップ挿入する操作である。
- 前回のペーストで追加されたゲートが `insertStartStep` 以降に存在する場合、それらも次回ペースト時の押し出し対象となる。

#### 複数ゲートのペースト

- 複数量子ビットを含むペーストの場合、コピーしたゲート群の相対座標を維持したまま、右方向へ挿入する。
- とびとびの選択では、選択ゲートが存在しない中間ステップを除外して左詰めする。
- ペースト時の `insertWidth` は、コピー対象ゲートが存在するステップ数とする。
- H / X / Z のうち H と Z だけをコピーした場合、clipboard 内では H / Z の2ステップになる。
- 量子ビット方向の空きは接続構造に必要なため詰めず、元の相対位置を保持する。

#### 押し出し

- ペースト予定位置に既存ゲートが存在する場合、ペースト予定ステップ以降の既存ゲートを右方向へ押し出す。
- 押し出し対象は、対象ステップ以降に存在するすべての量子ビット上のゲートである。
- 制御ゲートやSWAPなど、複数量子ビットにまたがる構造は、接続関係を保持したまま押し出す。
- 表示上は、既存ゲートと制御ゲート・SWAPの縦接続線を短く滑らせて押し出しを表現する。
- 量子ビットの横線は、押し出しアニメーションの対象に含めない。
- 押し出し表示後、短い間を置いてペーストされたゲートと縦接続線を同時に表示する。

押し出しアニメーションは、回路データの正しいペースト状態を作った後、表示だけを一時的に戻す方式で実装する。

具体的には、押し出された既存ゲートと縦接続線へ、ペースト幅ぶん左方向の一時オフセットを与え、そのオフセットを0へ戻す。

ペーストされた新規ゲートを画面外や左端からスライドさせてはならない。

ペーストされた新規ゲートと、そのゲートに付随する縦接続線は、押し出しアニメーション後の短い遅延を挟んで同時に表示する。

量子ビットの横線は、既存の回路線として扱い、押し出しアニメーションや白い強調表示の対象にしない。

#### 制御ゲートを含むペースト

CNOTゲートに代表されるような、制御線でつながった制御ゲート構造が含まれる場合、接続されたゲートを1つの構造として同時にコピー・ペースト・押し出しする。

対象例:

- CNOT
- 制御Z
- 制御回転ゲート
- 制御H
- CCNOT
- SWAP

#### ペースト後処理

ペースト時、即座に通常の量子ゲート配置と同じ表示・更新処理を行う。

ペースト後は、挿入したステップを保持しつつ、ゲートが存在せず挿入アンカーでもない既存の空ステップを既存の整理規則で詰める。ゲート順序の変更や量子回路の最適化は行わない。

対象例:

- 量子状態の更新
- URLの更新
- 表示の更新
- 接続線の更新
- pastedGates の更新
- pastedSteps の更新

#### 連続ペースト

連続して `Ctrl+V` が実行された場合、同じ `pasteAnchorCell` を基準にペースト処理を繰り返す。

コピーした後に他の量子ゲートまたは空セルを選択した場合、そのセルが新しい挿入アンカーとなる。

ただし、Ctrl+V 実行後に `pasteAnchorCell` をペースト先へ自動更新してはならない。

#### ペースト強調表示

ペーストされたゲートは、直近の Ctrl+V により新規配置されたことが分かるように、ゲート全体へ半透明の白い表示を一時的に重ねる。
強調表示は、ペーストで新たに挿入されたゲート実体と、制御・SWAPの縦接続線に適用する。
量子ビットの横線は、強調表示の対象に含めない。

ペースト直後は、既存ゲートと縦接続線の押し出し表示を行い、その後にペーストされたゲートと縦接続線を同じタイミングで表示する。
表示されたペーストゲートには、不透明度35%の白い表示を重ねる。

ペースト強調表示に点線は使用しない。

白いペースト強調表示は、発光開始から0.5秒間かけて通常ゲート色へ滑らかにフェードアウトする。

初期値は以下とする。

- 押し出しアニメーション時間: 120ms
- ペースト表示までの遅延: 30ms
- 白い強調表示の不透明度: 35%
- フェードアウト時間: 500ms

この値は、実装後の操作感確認により調整してよい。

ペースト強調表示は、通常のゲート表示や選択枠の上に半透明の白い表示を重ねる補助表示である。

ペースト強調表示中も、選択状態そのものを変更してはならない。

フェードアウト完了後、ゲートは通常表示に戻る。

Ctrl+V により新規作成されたゲートは、`selectedGates` に自動追加しない。

#### ペースト位置の予告と表示範囲

- ペースト位置マーカーは `border-active` 色で表示し、青いステップマーカーと区別する。
- clipboard がある場合、`insertWidth × clipboard.height` の範囲を薄いプレビューで表示する。
- 必要な量子ビット線が現在の最下段より下にある場合、候補ではなく操作可能な量子ビット線として全ステップへ追加する。
- 追加された量子ビット線に合わせて、青いステップマーカーも最下段まで伸ばす。
- 量子ビット線を追加する場合は、追加数を画面上で通知する。
- `MAX_QUBIT_COUNT` を超える場合は、ペースト前に検証して理由を通知し、回路とUndo/Redo履歴を変更しない。
- ペースト範囲が右側の可視域外にある場合、挿入した範囲が見える位置へ自動スクロールする。

### Undo / Redo仕様

#### Ctrl+Z

Ctrl+Z は直前に回路を変更した操作をUndoする。

ペースト、ゲート配置・移動・削除・切り取り、Clearを、それぞれ1回分ずつUndo単位として扱う。

選択変更、挿入アンカー変更、Ctrl+Cは回路を変更しないためUndo対象外とする。

#### Ctrl+Y / Ctrl+Shift+Z

初期実装では、Redo を対象に含める。

Ctrl+Z によりUndoされた回路編集は、Ctrl+YまたはCtrl+Shift+ZによりRedoできる。

Redo は、Undoした1回分の回路編集を再適用する。

Undo 後に新しい回路編集が実行された場合、Redo履歴は破棄する。

#### Undo履歴の保存形式

各回路編集の実行直前に、空ステップを含む回路JSON全体をUndo履歴に保存する。

Undo時は、保存した回路JSON全体を用いて、直前の回路編集前の状態へ復元する。

Redo時は、Undo直前の回路JSON全体を用いて、Undo前の状態へ復元する。

初期実装では、差分履歴によるUndo/Redoは行わない。

将来的に履歴サイズやパフォーマンス上の問題が生じた場合のみ、差分履歴を検討する。

## 矩形選択

### ドラッグ矩形選択

ドラッグ矩形選択は、コピー対象をまとめて指定するための選択操作である。

#### 操作

- 量子ゲート・ステップバー以外の場所での、左クリックのドラッグで選択範囲を指定する。
- このドラッグ操作でステップバーは反応しない。
- 修飾キーなしのドラッグでは、ドラッグ開始前の選択を置き換える。
- Shift + ドラッグでは、ドラッグ開始前の選択へ追加する。

#### 選択条件

- 選択範囲が量子ゲートに触れたときに選択される。
- 空白をドラッグしても何も選択されない。

#### 制御ゲートの扱い

- ドラッグ矩形選択では、CNOTなどの制御ゲート構造は、選択範囲に触れたゲートのみ選択状態になる。
- CNOTなどの制御ゲート構造はまとめて選択されない。

#### 有効範囲

- ドラッグ矩形選択が有効なのは量子回路部分のみとする。
- パレットやメニューでは、ドラッグ矩形選択は無効とする。

#### 矩形表示

- ドラッグ操作が終了すると、つまりマウスを離すと、矩形は消える。
- 塗りは `bg-active` の不透明度12%、枠は `border-pressed` の1pxとし、下のゲートとワイヤが透けて見えるようにする。
