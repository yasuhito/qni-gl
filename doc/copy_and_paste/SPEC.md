# コピー＆ペースト機能 SPEC.md

## 説明

### 機能説明と背景

#### 課題

PCEにおける量子誤り検出デモで使用した量子回路の作成を通じ、本機能導入の必要性が明確になった。

量子アルゴリズムの量子回路を QniGPU 上で構築する際、量子ゲートを都度ドラッグ＆ドロップで配置する操作は、ゲート数の増加に伴い手間と時間が累積する。

特に CNOT ゲートとの組み合わせ、たとえば CNOT + S、CNOT + 位相、CNOT + H などは多くの量子アルゴリズムで登場する。
これらを繰り返し配置する場合、この問題が顕著になる。

改善目標は、操作回数と所要時間を削減し、回路構築の効率と正確性を高めることである。

#### 解決案

QniGPU にコピー＆ペースト機能を導入する。

本機能では、ペーストを「コピーした量子ゲート群を右方向にステップ挿入する操作」として定義する。

これにより、量子回路の編集における操作回数と編集時間を低減し、ユーザー生産性を向上させる。

#### 効果の試算

タイムアタックの試算は以下を前提とする。

- 単一ゲートドラッグ: 1.0 秒
- コピー / ペースト: 0.2 秒
- 回路内調整: 0.5 秒

従来の手順では、パレットからドラッグ 52 回で約 52 秒かかる作業が、本機能を用いることで合計約 15.8 秒となる。

作業時間で概ね 70% 程度の削減が見込まれる。
ドラッグ回数は 52 回から 4 回になり、約 92% 減となる。

#### 注意点

制御ゲートまとめて選択・ドラッグ矩形選択については初期実装の完了後、下方向ペーストについては必要性が判明してから実装する。

## 仕様

### 用語定義

| 用語 | 意味 |
|---|---|
| ゲート(量子ゲート) | H(アダマール)、X、S、T、制御(コントロール)ゲート、ターゲット、SWAPなど、量子回路上に配置される操作単位 |
| ステップ | 量子回路の縦の列。時間方向・右方向に増える単位 |
| 量子ビット | 水平方向の線として描画される行 |
| セル | 1つの量子ビット行と1つのステップ列が交差する位置。ゲートがフィッティングされ配置される場所 |
| 空セル | ゲート実体が存在しないセル。制御線だけが通っているセルも、ゲート実体がなければ空セルとして扱う |
| ゲート実体 | 選択・コピー・ペースト対象になる実際のゲート要素。制御線だけはゲート実体として扱わない |
| 制御線 | 制御ゲートとターゲットゲートを接続する線 |
| 制御ゲート構造 | 制御点、ターゲット、制御線を含む、CNOT・制御Z・制御H・CCNOTなどのまとまり |
| SWAP構造 | SWAPを構成する複数のSWAP部品と接続線のまとまり |
| selectedGates | 現在選択されているゲート集合。Ctrl+C のコピー対象 |
| activeCell | ペースト基準となるセル。Ctrl+V はこのセルの右隣を起点に実行する |
| clipboard | Ctrl+C により保存されたゲート集合、相対座標、接続情報 |
| pastedGates | 直近の Ctrl+V により新規配置されたゲート集合。紫点線枠の表示対象 |
| コピー範囲 | Ctrl+C 時に `selectedGates` から作られる、コピー対象ゲート群の外接範囲 |
| 相対座標 | コピー範囲内での各ゲートの相対的なステップ差分・量子ビット差分 |
| insertStartStep | ペースト挿入開始ステップ。通常は `activeCell.step + 1` |
| insertWidth | クリップボード内のステップ幅。既存ゲートを右へ押し出す幅でもある |
| 押し出し対象 | `insertStartStep` 以降に存在し、ペースト時に右方向へ移動される既存ゲート |
| Undo単位 | Ctrl+V 1回分の操作。ペーストされたゲート追加、押し出されたゲート位置、接続関係をまとめて復元する単位 |

### 状態定義

#### selectedGates

`selectedGates` は、コピー対象として選択されているゲート集合である。

- ゲートをクリックすると、そのゲートが `selectedGates` に入る。
- Shift + クリックにより、複数ゲートを `selectedGates` に追加できる。
- Ctrl+C は `selectedGates` をコピー対象とする。

#### activeCell

`activeCell` は、ペースト基準となるセルである。

- ゲートをクリックした場合、そのゲートが存在するセルを `activeCell` とする。
- 空セルをクリックした場合、その空セルを `activeCell` とする。
- Ctrl+V は `activeCell` を基準に実行する。

#### clipboard

`clipboard` は、Ctrl+C により保存されたゲート集合である。

保存する情報は以下とする。

- ゲート種類
- ステップ相対位置
- 量子ビット相対位置
- 制御ゲート・SWAPなどの接続情報
- 必要な描画・更新に必要な情報

#### pastedGates

`pastedGates` は、直近の Ctrl+V で追加されたゲート集合である。

- `pastedGates` は紫 `#6B15A8` の点線枠で強調する。
- 連続ペースト時は、最も新しいペースト結果を `pastedGates` とする。

---

### 選択仕様

#### 通常選択

- 量子ゲートの選択枠 `#5EEAD4` は、コピー対象ゲートを示す。
- 機能実装前の状態では、量子ゲートの `#5EEAD4` 色の枠は activeGate の UI として存在している。
- コピーしたい対象の量子ゲートを `#5EEAD4` 色の枠に切り替えて判断する。

#### 複数選択

- `Shift` キーを押し続けた状態で複数のゲートをクリックすると、複数選択できる。
- `Shift` を離して量子回路領域をクリックした場合、既存の複数選択はすべて解除される。

#### 制御ゲートの選択

- 制御ゲート、ターゲットゲートが制御線で接続されている場合（つまり制御ゲートとターゲットゲートが同じステップにある場合）、いずれかを選択すると制御ゲートを構成する量子ゲートすべて選択される。
- 制御ゲート自身もターゲットになりうる。
- 選択枠は通常の枠で表示される。
- 選択枠は制御ゲートをすべて囲うわけではない。
- コピー・ペースト時には、選択された要素が持つ制御線・接続情報は保持する。

対象例:

- CNOT
- 制御Z
- 制御回転ゲート
- 制御H
- CCNOT
- SWAP

#### 制御ゲートの一部選択

- 制御ゲートの構成する単一ゲートをダブルクリックすると、そのゲート単独の選択に切り替わる。
- 制御ゲートの一部だけを選択・コピー・ペースト可能。
- 接続情報を保持しない単独ゲートとして扱う。

#### 空セルの選択

- 空セルは、ペースト基準として選択可能とする。
- 制御線が描画されていても、そのセルにゲート実体が存在しない場合、そのセルは空セルとして扱う。

---

### コピー仕様

#### Ctrl+C

- `Ctrl+C` は、現在の `selectedGates` を `clipboard` に保存する。
- 選択したすべてのゲートは `Ctrl+C` でクリップボードに保存される。

#### 複数ゲートのコピー

- 複数の量子ゲートをコピーした場合、種類だけでなく構造(各量子ゲートのステップ・量子ビットの位置)を保存する。

保存対象は以下とする。

- どの量子ビットにあるか
- どのステップにあるか
- 選択ゲート群の相対座標
- 制御ゲートの接続関係
- SWAPなどの複数量子ビット構造

#### コピー保持

- 選択してコピー後、ブラウザを閉じたり、他ブラウザで操作があった場合を除き、コピーした量子ゲートを保持する。
- 複数選択しコピー後、`Shift` を離して量子回路領域をクリックした場合、既存の複数選択はすべて解除される。
- ただし、`clipboard` は保持される。

#### Undo操作

- `Ctrl+Z`１つでペースト操作を１つ戻す。
- ペーストを連続操作した場合、最初の状態まで遡上可能。
- `Ctrl+C` は Undo 対象外とする。

---

### ペースト仕様

#### 基本定義

`Ctrl+V` によるペーストは、コピーされた量子ゲート群を右方向にステップ挿入する操作である。

ペーストは上書きではない。
ペースト予定位置に既存ゲートが存在する場合、既存ゲートを右方向へステップごと押し出す。

#### ペースト基準

ペーストは `activeCell` を基準に実行する。

基本ルール:

- `activeCell`はコピーしたゲート群の最も右のステップ・最も上の量子ビットにする。
- コピーしたゲート群の挿入開始位置は、基準セル(`activeCell`)の1ステップ右とする。
  - `insertStartStep = activeCell.step + 1`
- コピーしたゲート群の横幅を `insertWidth` とする。
  - `insertWidth = clipboard.maxStep - clipboard.minStep + 1`
- ペースト時は`insertStartStep` 以降の既存ゲートを `insertWidth` 分だけ右方向へ押し出す。
- clipboard 内の最小 step・最小 qubit の位置を、`insertStartStep` と `activeCell.qubit` に合わせて配置する。
- その他のゲートは、clipboard 内の相対座標を維持して配置する。

#### 複数ゲートのペースト

- 複数量子ビットを含むペーストの場合、コピーしたゲート群の相対座標を維持したまま、右方向へ挿入する。
- とびとびの選択でコピー・ペーストされた場合でも、構造を保持する。

#### 押し出し

- ペースト予定位置に既存ゲートが存在する場合、ペースト予定ステップ以降の既存ゲートを右方向へ押し出す。
- 押し出し対象は、対象ステップ以降に存在するすべての量子ビット上のゲートである。
- 制御ゲートやSWAPなど、複数量子ビットにまたがる構造は、接続関係を保持したまま押し出す。

#### 制御ゲートを含むペースト

CNOTゲートに代表されるような、制御線でつながった制御ゲートが含まれる場合、接続されたゲートを1つの構造として同時にコピー・ペースト・押し出しする。

対象例:

- CNOT
- 制御Z
- 制御回転ゲート
- 制御H
- CCNOT
- SWAP

#### ペースト後処理

ペースト時、即座に通常の量子ゲート配置と同じ処理を行う。

対象例:

- 量子状態の更新
- URLの更新
- 表示の更新
- pastedGates の更新

#### 連続ペースト

連続して `Ctrl+V` が実行された場合、同じペースト処理を繰り返す。

コピーした後に他の量子ゲートまたは空セルを選択した場合、そのセルが新しいペースト基準となる。

#### ペースト強調表示

ペーストされたゲートは、紫 `#6B15A8` の点線枠で強調される。

連続でペーストされた場合、最も新しいペーストされたゲートが紫 `#6B15A8` の点線枠で強調される。

---

### ペースト処理の疑似コード

```txt
1. clipboard が空なら何もしない。
2. activeCell が存在しない場合は何もしない。
3. insertStartStep = activeCell.step + 1 とする。
4. insertWidth = clipboard.maxStep - clipboard.minStep + 1 とする。
5. insertStartStep 以降の既存ステップを insertWidth 分だけ右へ移動する。
6. clipboard 内の各ゲートを相対座標を維持して配置する。
7. pastedGates を新規配置ゲート集合に更新する。
8. 量子状態とURLを更新する。
9. 操作全体を1つのUndo単位として記録する。
```

---

### Undo仕様

#### Ctrl+Z

Ctrl+V によるペースト操作を1単位としてCtrl+Zで Undo 可能にする。

#### Undo対象

Undoでは以下を復元する。

- ペースト前の量子回路状態
- 回路の移動・削除

#### Undo対象外

Ctrl+C は Undo 対象外とする。

## 後続実装予定

### ドラッグ矩形選択

ドラッグ矩形選択は、初期実装が終了次第、実装予定とする。

#### 操作

- 量子ゲート・ステップバー以外の場所での、左クリックのドラッグで選択範囲を指定する。
- このドラッグ操作でステップバーは反応しない。

#### 選択条件

- 選択範囲が量子ゲートに触れたときに選択される。
- 空白をドラッグしても何も選択されない。

#### 制御ゲートの扱い

- ドラッグ矩形選択では、CNOTなどの制御ゲートは、選択範囲に触れたゲートのみ選択状態になる。
- CNOTなどの制御ゲートはまとめて選択されない。

#### 有効範囲

- ドラッグ矩形選択が有効なのは量子回路部分のみとする。
- パレットやメニューでは、ドラッグ矩形選択は無効とする。

#### 矩形表示

- ドラッグ操作が終了すると、つまりマウスを離すと、矩形は消える。

## テストで確認すべき項目

- コピーなしで Ctrl+V しても壊れないこと
- selectedGates なしで Ctrl+C しても壊れないこと
- 単一Hゲートをコピー＆ペーストできること
- 既存ゲートがある位置にペーストした場合、既存ゲートが右へ押し出されること
- 既存CNOTがある位置にペーストした場合、CNOT構造を保持したまま押し出されること
- 複数ゲートをコピー＆ペーストできること
- とびとび選択をコピー＆ペーストできること
- 空セルをペースト基準にできること
- 制御線のみが通るセルを空セルとして扱えること
- SWAPを構造としてコピー＆ペーストできること
- CCNOTを構造としてコピー＆ペーストできること
- Ctrl+V後にCtrl+Zで完全復元できること
- Ctrl+CはUndo対象外であること
- ペースト後、量子状態とURLが更新されること
- ペースト処理自身では空ステップ圧縮しないこと
