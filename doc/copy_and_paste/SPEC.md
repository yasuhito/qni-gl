# コピー＆ペースト機能 SPEC.md

## 説明

### 機能説明と背景

#### 課題

PCEにおける量子誤り検出デモで使用した量子回路の作成を通じ、本機能導入の必要性が明確になった。

量子アルゴリズムの量子回路を QniGPU 上で構築する際、量子ゲートを都度ドラッグ＆ドロップで配置する操作は、ゲート数の増加に伴い手間と時間が累積する。

特に CNOT ゲートとの組み合わせ、たとえば CNOT + S、CNOT + 位相、CNOT + H などは多くの量子アルゴリズムで登場する。
これらを繰り返し配置する場合、この問題が顕著になる。

改善目標は、操作回数と所要時間を削減し、回路構築の効率と正確性を高めることである。

#### 解決案

QniGPU にコピー＆ペースト機能を導入する。

本機能では、ペーストを「コピーした量子ゲート群を右方向にステップ挿入する操作」として定義する。

これにより、量子回路の編集における操作回数と編集時間を低減し、ユーザー生産性を向上させる。

#### 効果の試算

タイムアタックの試算は以下を前提とする。

- 単一ゲートドラッグ: 1.0 秒
- コピー / ペースト: 0.2 秒
- 回路内調整: 0.5 秒

従来の手順では、パレットからドラッグ 52 回で約 52 秒かかる作業が、本機能を用いることで合計約 15.8 秒となる。

作業時間で概ね 70% 程度の削減が見込まれる。
ドラッグ回数は 52 回から 4 回になり、約 92% 減となる。

#### 注意点

制御ゲート構造のまとめて選択は初期実装対象とする。

ドラッグ矩形選択はコピー対象を効率よく指定するための選択手段として扱う。

下方向ペーストについては必要性が判明してから実装する。

### 用語定義

| 用語 | 意味 |
|---|---|
| ゲート(量子ゲート) | H(アダマール)、X、S、T、制御ゲート、ターゲットゲート、SWAPなど、量子回路上に配置される操作単位 |
| ステップ | 量子回路の縦の列。時間方向・右方向に増える単位 |
| 量子ビット | 水平方向の線として描画される行 |
| セル | 1つの量子ビット行と1つのステップ列が交差する位置。ゲートがフィッティングされ配置される場所 |
| 空セル | ゲート実体が存在しないセル。制御線だけが通っているセルも、ゲート実体がなければ空セルとして扱う |
| ゲート実体 | 選択・コピー・ペースト対象になる実際のゲート要素。制御線だけはゲート実体として扱わない |
| 制御線 | 制御ゲートとターゲットゲートを接続する線 |
| 制御ゲート構造 | 制御ゲート、ターゲットゲート、制御線、接続情報を含む、CNOT・制御Z・制御H・CCNOTなどのまとまり |
| SWAP構造 | SWAPを構成する複数のSWAP部品と接続線のまとまり |
| selectedGates | 現在選択されているゲート集合。Ctrl+C のコピー対象 |
| activeCell | ペースト基準となるセル。Ctrl+V はこのセルの右隣を起点に実行する |
| clipboard | Ctrl+C により保存されたゲート集合、相対座標、接続情報 |
| pastedGates | 直近の Ctrl+V により新規配置されたゲート集合 |
| pastedSteps | 直近の Ctrl+V により新規配置されたゲートを含むステップ集合。白いフェード強調表示の対象 |
| コピー範囲 | Ctrl+C 時に `selectedGates` から作られる、コピー対象ゲート群の外接範囲 |
| 相対座標 | コピー範囲内での各ゲートの相対的なステップ差分・量子ビット差分 |
| insertStartStep | ペースト挿入開始ステップ。通常は `activeCell.step + 1` |
| insertWidth | クリップボード内のステップ幅。既存ゲートを右へ押し出す幅でもある |
| 押し出し対象 | `insertStartStep` 以降に存在し、ペースト時に右方向へ移動される既存ゲート |
| Undo単位 | Ctrl+V 1回分の操作。ペーストされたゲート追加、押し出されたゲート位置、接続関係をまとめて復元する単位 |

### 状態定義

#### selectedGates

`selectedGates` は、コピー対象として選択されているゲート集合である。

- ゲートをクリックすると、そのゲートが `selectedGates` に入る。
- 通常クリックで別のゲートを選択した場合、既存の `selectedGates` は解除され、クリックしたゲートに置き換わる。
- Shift + クリックにより、複数ゲートを `selectedGates` に追加できる。
- Ctrl+C は `selectedGates` をコピー対象とする。
- `selectedGates` と `clipboard` は独立した状態である。
- 新たなゲート選択や空セル選択が行われても、既存の `clipboard` は変更しない。

#### activeCell

`activeCell` は、ペースト基準となるセルである。

- ゲートをクリックした場合、そのゲートが存在するセルを `activeCell` とする。
- 通常クリックでゲートを選択した場合、`activeCell` はそのゲートのセルに更新する。
- 空セルをクリックした場合、その空セルを `activeCell` とする。
- 空セルクリックでは、既存の `selectedGates` は解除しない。
- Ctrl+C 実行時、`activeCell` はコピー範囲の右上セルに更新する。
- Ctrl+V は `activeCell` を基準に実行する。
- Ctrl+V 実行後、`activeCell` は自動更新しない。
- 連続して Ctrl+V が実行された場合も、同じ `activeCell` を基準にペーストする。
- 量子回路外やセル以外の背景クリックでは、`selectedGates` の選択枠を解除してよい。
- ただし、背景クリックで `activeCell` と空セル選択枠を解除してはならない。
- 空セルが `activeCell` でなくなった場合、その空セルだけで構成される空ステップは既存の回路整理機能で詰めてよい。
- 新たに選択された空セルのステップは、ペースト基準として残すため詰めてはならない。

#### clipboard

`clipboard` は、Ctrl+C により保存されたゲート集合である。

保存する情報は以下とする。

- ゲート種類
- ステップ相対位置
- 量子ビット相対位置
- 制御ゲート・SWAPなどの接続情報
- 必要な描画・更新に必要な情報

`clipboard` の更新ルールは以下とする。

- `clipboard` は Ctrl+C 実行時のみ更新する。
- 新たなゲート選択、Shift + クリック、空セル選択、Ctrl+V、Ctrl+Z、Ctrl+Shift+Z では `clipboard` を変更しない。
- `selectedGates` が空の場合、Ctrl+C は何もしない。
- `selectedGates` が空の Ctrl+C でも、既存の `clipboard` は保持する。

#### pastedGates

`pastedGates` は、直近の Ctrl+V で追加されたゲート集合である。

- `pastedGates` は、ペースト後の強調対象ステップを決めるために使用する。
- ペーストされたゲートは `selectedGates` に自動追加しない。
- 連続ペースト時、今回新しく作成されたゲートは新たにペースト強調表示を開始する。
- 前回の Ctrl+V で作成されたゲートが、今回の Ctrl+V により右方向へ押し出された場合でも、そのゲートのフェードアウトは停止しない。
- 押し出された前回ペーストゲートは、既に開始しているフェードアウトをそのまま継続する。

#### pastedSteps

`pastedSteps` は、直近の Ctrl+V で新規配置されたゲートを含むステップ集合である。

- ペースト強調表示は、`pastedSteps` に含まれるステップ全体へ適用する。
- 強調対象には、ゲート実体、制御ゲート・SWAPの接続線、関連するワイヤを含める。
- ゲートと接続線で白さやフェード量に差が出ないよう、同じ不透明度と同じフェード時間を使用する。
- 押し出されただけの既存ステップは、今回の `pastedSteps` に含めない。

### 選択仕様

#### 通常選択

- 量子ゲートの選択枠 `border-active` は、コピー対象ゲートを示す。
- 機能実装前の状態では、量子ゲートの `border-active` 色の枠は activeGate の UI として存在している。
- コピーしたい対象の量子ゲートを `border-active` 色の枠に切り替えて判断する。
- 選択枠は、現在のコピー対象およびペースト基準を示す恒常的な表示である。
- 初期状態では、ゲートまたは空セルがまだ選択されていないため、選択枠は表示されない。
- 一度ゲートまたは空セルが選択された後、選択枠は表示され続ける。
- 選択枠は、ペースト後も解除しない。
- 選択枠は、新たなゲート選択または空セル選択により更新される。
- Clear、リロード、または回路を初期状態へ戻す操作が行われた場合、選択枠は初期状態に戻り、表示されない。

#### 複数選択

- `Shift` キーを押し続けた状態で複数のゲートをクリックすると、複数選択できる。
- Shift + クリックにより、既存の `selectedGates` にゲートを追加できる。
- 通常クリックで別のゲートを選択した場合、既存の `selectedGates` は解除され、クリックしたゲートに置き換わる。
- 空セルクリックでは、既存の `selectedGates` は解除しない。

#### 制御ゲートの選択

制御ゲート構造は、制御ゲート、ターゲットゲート、制御線、接続情報から構成される。

制御ゲートまたはターゲットゲートをシングルクリックした場合、そのゲートが属する接続構造全体を選択する。

CNOTの場合、制御ゲートをシングルクリックしても、ターゲットゲートをシングルクリックしても、CNOT構造全体を選択する。

通常ゲートが同じステップに複数並んでいるだけの場合、それらは接続構造として扱わない。

たとえば、同じステップに H / S / T が並んでいても、Hをクリックしただけで S / T まで選択してはならない。

制御ゲート構造やSWAP構造のまとめて選択は、ゲート名、表示形状、SVG上の見た目から判定してはならない。

まとめて選択する対象は、既存の回路データが持つ接続情報を正として判定する。

制御線の描画オブジェクトはゲート実体ではないため、選択対象には含めない。

対象例:

- CNOT
- 制御Z
- 制御回転ゲート
- 制御H
- CCNOT
- SWAP

#### 制御ゲートの一部選択

制御ゲートまたはターゲットゲートをダブルクリックした場合、そのクリックされたゲート実体だけを単独選択する。

制御ゲートをダブルクリックした場合、その制御ゲートだけを単独選択する。

ターゲットゲートをダブルクリックした場合、そのターゲットゲートだけを単独選択する。

単独選択された制御ゲートまたはターゲットゲートを Ctrl+C した場合、接続構造全体を自動でコピーしてはならない。

この場合、選択された1個のゲート実体だけをコピーする。

制御ゲートを単独コピーした場合、ペースト後も単独の制御ゲートとして配置する。

制御線は、制御ゲート単独が保持するものではない。

制御線は、同じステップ内に接続対象となるゲートが存在する場合に描画・更新される。

制御ゲートの接続対象は、Qni内部で「制御可能」と定義されているゲートに限る。

測定ゲート、初期化ゲート、ブロッホ球など、Qni内部で制御可能と定義されていない要素は、同じステップ内に存在しても制御ゲートとは接続しない。

#### 空セルの選択

- 空セルは、ペースト基準として選択可能とする。
- 制御線が描画されていても、そのセルにゲート実体が存在しない場合、そのセルは空セルとして扱う。
- 空セルクリックは、ペースト基準セルの変更であり、既存の `selectedGates` を解除する操作ではない。
- 空セルを選択しても、既存の選択ゲート枠は維持する。
- 空セル選択枠は、ゲート選択枠と同じ `border-active` の枠を使用する。
- ただし、空セル選択枠には `rgba(113, 113, 122, 0.12)` 程度の薄いグレー塗りを付ける。
- 空セル選択は、Dropzone またはセル領域に対するクリックで発生する。
- 回路グリッド内であっても、Dropzone / セル領域に入っていないクリックは、空セル選択として扱わない。
- ワイヤ上のクリックであっても、Dropzone / セル領域外であれば `activeCell` は変更しない。
- クリック位置を最も近いセルへ自動補正してはならない。
- 量子回路外やセル以外の背景クリックでは、空セルのペースト基準は解除しない。
- 空セルを選択した後、別のゲートまたは別ステップの空セルを選択した場合、前の空セルは `activeCell` ではなくなる。
- 前の空セルだけで構成される空ステップは、その時点で既存の回路整理機能により詰める。
- 同じステップ内の別セルへペースト基準を移した場合、そのステップは詰めない。

#### ステップバーの扱い

回路グリッド内には、各ステップの量子状態を表示するためのステップバーが存在する。

ステップバーは、ゲート配置セルではない。

ステップバーをクリックした場合、既存のステップ選択・量子状態表示切り替え処理を行う。

ステップバーのクリックは、空セル選択として扱わない。

ステップバーのクリックにより `activeCell` を変更してはならない。

ステップバーのクリックにより `selectedGates` を解除してはならない。

ステップバーは、コピー＆ペースト機能におけるペースト基準セルではない。

### コピー仕様

#### Ctrl+C

- `Ctrl+C` は、現在の `selectedGates` を `clipboard` に保存する。
- 選択したすべてのゲートは `Ctrl+C` でクリップボードに保存される。
- `selectedGates` が空の場合、Ctrl+C は何もしない。
- このとき、既存の `clipboard` は変更しない。
- Ctrl+C を実行した場合、`activeCell` はコピー範囲の右上セルに更新する。
- コピー範囲の右上セルとは、`selectedGates` の中で最も右にあるステップ、かつ最も上にある量子ビットのセルである。
- Ctrl+C 後に別のゲートまたは空セルを選択した場合、`activeCell` はその選択先に更新される。
- ただし、`clipboard` は新たな Ctrl+C が実行されるまで変更しない。

#### 複数ゲートのコピー

- 複数の量子ゲートをコピーした場合、種類だけでなく構造(各量子ゲートのステップ・量子ビットの位置)を保存する。

保存対象は以下とする。

- どの量子ビットにあるか
- どのステップにあるか
- 選択ゲート群の相対座標
- 制御ゲートの接続関係
- SWAPなどの複数量子ビット構造

#### コピー保持

- 選択してコピー後、ブラウザを閉じたり、他ブラウザで操作があった場合を除き、コピーした量子ゲートを保持する。
- 複数選択しコピー後、新たなゲート選択または空セル選択が行われても、既存の `clipboard` は保持される。
- `clipboard` が更新されるのは、新たに Ctrl+C が実行された場合のみである。

### ペースト仕様

#### 基本定義

`Ctrl+V` によるペーストは、コピーされた量子ゲート群を右方向にステップ挿入する操作である。

ペーストは上書きではない。

ペースト予定位置に既存ゲートが存在する場合、既存ゲートを右方向へステップごと押し出す。

#### ペースト基準

ペーストは `activeCell` を基準に実行する。

基本ルール:

- `activeCell` はコピーしたゲート群の最も右のステップ・最も上の量子ビットにする。
- コピーしたゲート群の挿入開始位置は、基準セル(`activeCell`)の1ステップ右とする。
  - `insertStartStep = activeCell.step + 1`
- コピーしたゲート群の横幅を `insertWidth` とする。
  - `insertWidth = clipboard.maxStep - clipboard.minStep + 1`
- ペースト時は `insertStartStep` 以降の既存ゲートを `insertWidth` 分だけ右方向へ押し出す。
- clipboard 内の最小 step・最小 qubit の位置を、`insertStartStep` と `activeCell.qubit` に合わせて配置する。
- その他のゲートは、clipboard 内の相対座標を維持して配置する。
- Ctrl+V 実行後、`activeCell` は自動更新しない。
- 連続して Ctrl+V が実行された場合も、同じ `activeCell` を基準にペーストする。
- Ctrl+V の連打は、末尾へ追記する操作ではなく、同じ基準セルの右側へ繰り返しステップ挿入する操作である。
- 前回のペーストで追加されたゲートが `insertStartStep` 以降に存在する場合、それらも次回ペースト時の押し出し対象となる。

#### 複数ゲートのペースト

- 複数量子ビットを含むペーストの場合、コピーしたゲート群の相対座標を維持したまま、右方向へ挿入する。
- とびとびの選択でコピー・ペーストされた場合でも、構造を保持する。
- ペースト時の `insertWidth` は、コピー範囲の外接ステップ幅とする。
- `insertWidth = clipboard.maxStep - clipboard.minStep + 1` とする。
- コピー対象ゲートがとびとびのステップに存在する場合でも、中間の空ステップを含めた幅を `insertWidth` とする。
- 中間の空ステップは、コピーされたゲート群の時間方向の相対構造の一部として扱う。
- ペースト時に、中間の空ステップを詰めてはならない。

#### 押し出し

- ペースト予定位置に既存ゲートが存在する場合、ペースト予定ステップ以降の既存ゲートを右方向へ押し出す。
- 押し出し対象は、対象ステップ以降に存在するすべての量子ビット上のゲートである。
- 制御ゲートやSWAPなど、複数量子ビットにまたがる構造は、接続関係を保持したまま押し出す。

#### 制御ゲートを含むペースト

CNOTゲートに代表されるような、制御線でつながった制御ゲート構造が含まれる場合、接続されたゲートを1つの構造として同時にコピー・ペースト・押し出しする。

対象例:

- CNOT
- 制御Z
- 制御回転ゲート
- 制御H
- CCNOT
- SWAP

#### ペースト後処理

ペースト時、即座に通常の量子ゲート配置と同じ表示・更新処理を行う。

ただし、ペースト処理自身で空ステップ圧縮、量子回路の最適化、ゲート順序の再配置を行ってはならない。

対象例:

- 量子状態の更新
- URLの更新
- 表示の更新
- 接続線の更新
- pastedGates の更新
- pastedSteps の更新

#### 連続ペースト

連続して `Ctrl+V` が実行された場合、同じ `activeCell` を基準にペースト処理を繰り返す。

コピーした後に他の量子ゲートまたは空セルを選択した場合、そのセルが新しいペースト基準となる。

ただし、Ctrl+V 実行後に `activeCell` をペースト先へ自動更新してはならない。

#### ペースト強調表示

ペーストされたゲートは、直近の Ctrl+V により新規配置されたことが分かるように、ゲート全体へ半透明の白い表示を一時的に重ねる。
強調表示は、ペーストで新たに挿入されたステップの描画全体に適用し、ゲート実体、制御・SWAPの接続線、関連するワイヤを同じ効果で表示する。

ペースト直後は、まず通常色のゲートを表示する。50ms後にゲートの枠と塗りを覆う、不透明度35%の白い表示を重ねる。

ペースト強調表示に点線は使用しない。

白いペースト強調表示は、発光開始から0.5秒間かけて通常ゲート色へ滑らかにフェードアウトする。

初期値は以下とする。

- 発光開始までの遅延: 50ms
- フェードアウト時間: 500ms

この値は、実装後の操作感確認により調整してよい。

ペースト強調表示は、通常のゲート表示や選択枠の上に半透明の白い表示を重ねる補助表示である。

ペースト強調表示中も、通常ゲート、接続線、選択状態そのものを変更してはならない。

フェードアウト完了後、ゲートは通常表示に戻る。

Ctrl+V により新規作成されたゲートは、`selectedGates` に自動追加しない。

### ペースト処理の疑似コード

```txt
1. clipboard が空なら何もしない。
2. activeCell が存在しない場合は何もしない。
3. insertStartStep = activeCell.step + 1 とする。
4. insertWidth = clipboard.maxStep - clipboard.minStep + 1 とする。
5. insertStartStep 以降の既存ステップを insertWidth 分だけ右へ移動する。
6. clipboard 内の各ゲートを相対座標を維持して配置する。
7. pastedGates を新規配置ゲート集合に更新する。
8. pastedSteps を新規配置ゲートを含むステップ集合に更新する。
9. 量子状態とURLを更新する。
10. 操作全体を1つのUndo単位として記録する。
11. activeCell は更新しない。
12. selectedGates は解除しない。
13. clipboard は変更しない。
```

### Undo / Redo仕様

#### Ctrl+Z

初期実装では、Ctrl+Z は Ctrl+V によるペースト操作のみを Undo 対象とする。

Ctrl+V 1回分を1つの Undo 単位として扱う。

Ctrl+C は Undo 対象外とする。

通常のゲート配置、削除、ドラッグ移動などは、初期実装ではコピー＆ペースト機能の Undo 対象外とする。

#### Ctrl+Shift+Z

初期実装では、Redo を対象に含める。

Ctrl+Z により Undo されたペースト操作は、Ctrl+Shift+Z により Redo できる。

Redo は、Ctrl+V 1回分のペースト操作を再適用する。

Undo 後に新しい Ctrl+V が実行された場合、Redo履歴は破棄する。

#### Undo履歴の保存形式

初期実装では、Ctrl+V 実行直前の回路JSON全体をUndo履歴に保存する。

Undo時は、保存した回路JSON全体を用いて、ペースト前の状態へ復元する。

Redo時は、Undo直前の回路JSON全体を用いて、Undo前の状態へ復元する。

初期実装では、差分履歴によるUndo/Redoは行わない。

将来的に履歴サイズやパフォーマンス上の問題が生じた場合のみ、差分履歴を検討する。

## 矩形選択

### ドラッグ矩形選択

ドラッグ矩形選択は、コピー対象をまとめて指定するための選択操作である。

#### 操作

- 量子ゲート・ステップバー以外の場所での、左クリックのドラッグで選択範囲を指定する。
- このドラッグ操作でステップバーは反応しない。

#### 選択条件

- 選択範囲が量子ゲートに触れたときに選択される。
- 空白をドラッグしても何も選択されない。

#### 制御ゲートの扱い

- ドラッグ矩形選択では、CNOTなどの制御ゲート構造は、選択範囲に触れたゲートのみ選択状態になる。
- CNOTなどの制御ゲート構造はまとめて選択されない。

#### 有効範囲

- ドラッグ矩形選択が有効なのは量子回路部分のみとする。
- パレットやメニューでは、ドラッグ矩形選択は無効とする。

#### 矩形表示

- ドラッグ操作が終了すると、つまりマウスを離すと、矩形は消える。
