# コピー＆ペースト機能

### 課題
PCEにおける量子誤り検出デモで使用した量子回路の作成を通じ、本機能導入の必要性が明確になりました。
量子アルゴリズムの量子回路を Qni 上で構築する際、量子ゲートを都度ドラッグ＆ドロップで配置する操作は、ゲート数の増加に伴い手間と時間が累積します。
特に CNOT ゲートとの組み合わせ(例：CNOT + Rz、CNOT + 位相、CNOT + H + …）は多くの量子アルゴリズムで登場し、これらを繰り返し配置する場合、この問題が顕著です。

改善目標は、操作回数と所要時間を削減し、回路構築の効率と正確性を高めることです。

### 解決案
Qni にクリップボード機能を導入し、ペースト方向を「右」「下」の二種類で定義します。
ゲート選択時に青い枠のカーソルを表示してペーストの基準とし、複数ゲート選択やワイヤ接続されたゲートのまとまった選択をサポートします。
本機能により量子回路の編集における操作回数と編集時間を低減し、ユーザー生産性を向上させます。

タイムアタックの試算（前提：単一ゲートドラッグ = 1.0 秒、コピー／ペースト = 0.2 秒、回路内調整 = 0.5 秒）では、従来の手順（パレットからドラッグ 52 回）で約 52 秒かかる作業が、本機能を用いることで合計約 15.8 秒となり、作業時間で概ね 70% 程度の削減が見込まれます（ドラッグ回数は 52 回 → 4 回、約 92% 減）。

### 注意点

---

## 1) 基本操作
最小限の操作でコピー・ペーストできるようにして手間を減らす。

1. ペーストの基準は「カーソル」（青い四角）とし、量子ビットをクリックした時に表示し複製の基準点とする。 デフォルトはカーソルがない状態。 
2. `Ctrl+C` で現在の選択をクリップボードに保存する。  
3. `Ctrl+V`（右ペースト）で選択内容を同一列の右隣に挿入し、該当列の既存ゲートを右へ押し出す。  
4. `Ctrl+Shift+V`（下ペースト）で選択内容を下方向に挿入する（最大32量子ビット）。

## 2) 複数選択
複数のゲートをまとめて移動・複製し、操作回数を減らす。

1. `Shift+クリック` により任意の複数ゲートを選択できる。  
2. 選択解除は任意の領域をクリック。量子ゲートをクリックした場合、個別の選択状態になる。
3. ワイヤで接続された複数量子ゲート（例：CNOT）は、初回クリックでまとまりとして選択される（まとまり選択）。  
4. まとまりの解除→個別選択は二段階で行う：一度目のクリックでまとまり選択、同要素を再クリックで個別選択へ切り替える。  
5. 複数選択は基本操作（節1）のコマンドでコピー／右ペースト／下ペーストが可能である。  
6. ドラッグ移動はクリックホールドで開始し、短いクリック（ホールドしない）で二段階の単独選択へ切り替える挙動をサポートする。

## 3) ペースト（単一選択）
動作の詳細を説明する。

1. 右ペーストは基準カーソルの列(ステップ)を右へ押し出して挿入する。  
2. 下ペーストは量子ビット行を追加し、下に押し出して挿入する。  
3. 選択のカーソルがない場合はデフォルト挿入位置（右上）を用いる。  
4. ペースト後は自動で余白の調整が行われる。

## 4) ペースト（複数量子ビット）
動作の詳細を説明する。

1. 右ペースト時、選択分のステップごと挿入する。
2. 下ペースト時、選択分の量子ビット（行）を追加する。
3. 複数量子ビットのゲートをペースト時、基準は１量子ビット目。
4. 選択のカーソルがない場合はデフォルト挿入位置（右上）にゲートセットの最上部分を挿入する。
5. 32量子ビット目に、2量子ビット以上のゲートセットをペーストはできない。（コピーしたゲートの量子ビット分の余白が必要とする）

## 5) Iゲート（基準扱い）
非表示の I ゲートを選択可能にし、より柔軟なペーストを可能にする。

1. I ゲートは基準として選択可能とする。  
2. I ゲートをペースト基準にした場合、ペースト後に余白は詰められる。
3. ワイヤ途中に基準カーソルを配置でき、列・行の基準を柔軟に選択できるようにする。 

## 6) 連続操作
同一基準に対する繰り返し複製を高速化し、テンプレート作成やパターン配置を効率化する。

1. キー連打で連続ペーストを実行できる。 
4. 連続操作は右/下/単一/複数の各ペースト種別に適用可能。
